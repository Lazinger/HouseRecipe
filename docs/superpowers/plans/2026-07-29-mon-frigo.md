# Mon Frigo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a personal "Mon Frigo" inventory tab whose stock is subtracted from the cart's shopping list, with a "Validé" button in the cart that restocks the fridge from what was bought.

**Architecture:** Pure quantity-math helpers live in `public/js/recipes/quantity.js` (unit-tested in `quantity.test.mjs`, no DOM/network dependency). A new `public/js/planning/fridge.js` module owns the fridge's in-memory state, Supabase sync (personal per-account table `fridge_items`, same write-queue/offline pattern as the rest of the app), and the new "Mon Frigo" view. `public/js/planning/cart.js` is modified to subtract fridge stock when computing "à acheter", and gets a new "Validé" button that restocks the fridge and clears the cart.

**Tech Stack:** Vanilla JS ES modules, Supabase (Postgres + RLS, JS client), IndexedDB/localStorage for offline cache, `node --test`-free assert-based test scripts (project convention, see `quantity.test.mjs`).

## Global Constraints

- No bundler, no build step — every new file is a plain ES module served as-is; relative import paths must be exact.
- Personal per-account data (not shared across the household) — RLS scoped to `user_id = auth.uid()`, same pattern as `cart_state`/`meal_plan`, not `recipes`.
- No automated end-to-end tests in this project — DOM/Supabase-integrated code is verified manually in the Browser pane (established convention, see every prior spec in `docs/superpowers/specs/`). Pure functions in `quantity.js` DO get real unit tests in `quantity.test.mjs`, following its existing assert-based pattern (not `node:test`).
- Any change touching `public/sw.js`'s `APP_SHELL` must bump `CACHE_NAME` (currently `carnet-cache-v82`).
- Any change touching `supabase/schema.sql` must also be applied live via the Supabase MCP tool (`apply_migration`, project_id `bmotbwubruvsrflaufis`) — editing the file alone does not change the live database. Ask the user for confirmation before applying, per established project practice.

```js
/* ---- soustraction d'un stock (frigo) au besoin d'une recette : utilisée
   par le panier pour n'afficher dans "à acheter" que ce qui manque
   reellement. Si l'une des deux quantites ne se parse pas, ou si les
   unites different, retourne le besoin inchange (repli sur : pas de
   deduction plutot qu'un calcul faux). ---- */
export function subtractQuantity(need, stock){
  const parsedNeed = parseQuantity(need);
  const parsedStock = parseQuantity(stock);
  if (!parsedNeed || !parsedStock) return need;
  if (parsedNeed.unit.toLowerCase() !== parsedStock.unit.toLowerCase()) return need;
  const remaining = Math.max(0, parsedNeed.value - parsedStock.value);
  const formatted = formatScaledNumber(remaining);
  return parsedNeed.unit ? `${formatted} ${parsedNeed.unit}` : formatted;
}
```

```js
/* ---- deduit le stock du frigo du besoin fusionne du panier : un
   ingredient dont le besoin tombe a zero est retire de la liste "a
   acheter". Correspondance par nom normalise (meme regle que la fusion
   du panier), pas de correspondance -> besoin brut inchange (repli sur). ---- */
export function applyFridgeStock(merged, fridgeItems){
  const fridgeMap = new Map(fridgeItems.map(([name, qty]) => [name.trim().toLowerCase(), qty]));
  return merged
    .map(item => {
      const stock = fridgeMap.get(item.key);
      if (!stock) return item;
      return { ...item, qty: subtractQuantity(item.qty, stock) };
    })
    .filter(item => {
      const parsed = parseQuantity(item.qty);
      return !(parsed && parsed.value === 0);
    });
}
```

```js
import { supabase, currentUserId } from "../auth/supabase-client.js";
import { enqueue, registerHandler } from "../core/write-queue.js";
import { mergeQuantityParts } from "../recipes/quantity.js";

/* ---- frigo personnel (persisté, une ligne par ingrédient et par compte) ---- */
const FRIDGE_KEY = "carnet-frigo";

function loadFridgeLocal(){
  try { return JSON.parse(localStorage.getItem(FRIDGE_KEY) || "[]"); }
  catch { return []; }
}
function saveFridgeLocal(){
  localStorage.setItem(FRIDGE_KEY, JSON.stringify(fridgeItems));
}

export const fridgeItems = loadFridgeLocal(); // Array<[name, qty]>

async function fridgeWriteHandler(payload){
  const userId = await currentUserId();
  if (!userId) return;
  if (payload.op === "delete") {
    const { error } = await supabase.from("fridge_items").delete().eq("user_id", userId).eq("name", payload.name);
    if (error) throw error;
  } else {
    const { error } = await supabase.from("fridge_items").upsert({
      user_id: userId, name: payload.name, qty: payload.qty, updated_at: new Date().toISOString()
    }, { onConflict: "user_id,name" });
    if (error) throw error;
  }
}
registerHandler("fridge", fridgeWriteHandler);

export async function initFridgeSync(){
  try {
    const userId = await currentUserId();
    if (!userId) return;
    const { data, error } = await supabase.from("fridge_items").select("name, qty").eq("user_id", userId);
    if (error) throw error;
    fridgeItems.splice(0, fridgeItems.length, ...(data || []).map(row => [row.name, row.qty]));
    saveFridgeLocal();
  } catch {
    /* hors-ligne ou erreur réseau : on garde le frigo déjà en cache localStorage */
  }
}

function findFridgeIndex(name){
  const key = name.trim().toLowerCase();
  return fridgeItems.findIndex(([n]) => n.trim().toLowerCase() === key);
}

export function saveFridgeItem(name, qty){
  const idx = findFridgeIndex(name);
  if (idx >= 0) fridgeItems[idx] = [name, qty]; else fridgeItems.push([name, qty]);
  saveFridgeLocal();
  const payload = { op: "upsert", name, qty };
  fridgeWriteHandler(payload).catch(() => enqueue("fridge", `upsert:${name.trim().toLowerCase()}`, payload));
}

export function removeFridgeItem(name){
  const idx = findFridgeIndex(name);
  if (idx >= 0) fridgeItems.splice(idx, 1);
  saveFridgeLocal();
  const payload = { op: "delete", name };
  fridgeWriteHandler(payload).catch(() => enqueue("fridge", `delete:${name.trim().toLowerCase()}`, payload));
}

/* ---- reapprovisionnement au clic sur "Valide" dans le panier : items est
   la liste "a acheter" telle qu'affichee ([{name, qty}]), s'additionne a
   ce qui existe deja pour chaque ingredient (meme regle de fusion que le
   panier). ---- */
export function incrementFridgeItems(items){
  items.forEach(({ name, qty }) => {
    const idx = findFridgeIndex(name);
    if (idx >= 0) {
      const [existingName, existingQty] = fridgeItems[idx];
      saveFridgeItem(existingName, mergeQuantityParts([existingQty, qty]));
    } else {
      saveFridgeItem(name, qty);
    }
  });
}
```

```js
    const oldName = row.dataset.savedName || "";
    if (oldName && oldName.toLowerCase() !== newName.toLowerCase()) removeFridgeItem(oldName);
    if (newName) {
      saveFridgeItem(newName, newQty);
      row.dataset.savedName = newName;
    } else {
      row.dataset.savedName = "";
    }
  };
  row.querySelector(".ing-name-input").addEventListener("change", commit);
  row.querySelector(".ing-qty-input").addEventListener("change", commit);

  row.querySelector(".dyn-remove").addEventListener("click", () => {
    if (row.dataset.savedName) removeFridgeItem(row.dataset.savedName);
  });

  container.appendChild(row);
  return row;
}
```
